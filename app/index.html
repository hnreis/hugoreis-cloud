Sobre a Infraestrutura

Esta aplicação está hospedada em um cluster gerenciado Kubernetes (OKE) na Oracle Cloud Infrastructure (OCI), operando sob uma topologia regional de alta disponibilidade com divisão estrita entre sub-redes públicas e privadas.

Especificações de Engenharia

  • Networking VCN com roteamento regional, Internet Gateway, NAT Gateway e Service Gateway.
  • Security Zero Trust com Network Security Groups (NSGs) isolando a borda dos nós de computação.
  • Compute Worker Nodes Ampere A1 (ARM64) com OKE gerenciado.
  • FinOps Arquitetura 100% elegível aos recursos Always Free com orçamento e alertas ativos.
